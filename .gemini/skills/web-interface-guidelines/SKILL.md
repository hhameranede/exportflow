# Web Interface Guidelines

Focused reference for ExportFlow, based on [vercel-labs/web-interface-guidelines](https://github.com/vercel-labs/web-interface-guidelines), licensed under MIT.

Read `references/web-interface-guidelines.md` when reviewing or implementing a web surface. Preserve semantic HTML, keyboard access, visible focus, labels and inline validation, touch-sized controls, reduced-motion behavior, responsive layouts, and precise UX copy. Apply only rules relevant to the actual interface; do not turn checklist conventions into needless UI decoration.
