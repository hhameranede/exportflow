# ExportFlow UI/UX skills and sources

Gemini has three focused interface-design skills in this repository:

| Skill | GitHub source | License | Focus |
| --- | --- | --- | --- |
| impeccable | https://github.com/pbakaus/impeccable | Apache-2.0 | Design critique, cognitive load, craft floor, audit, and polish |
| ui-ux-pro-max | https://github.com/nextlevelbuilder/ui-ux-pro-max-skill | MIT | Accessibility, interaction, responsive behavior, typography, and UX quality |
| web-interface-guidelines | https://github.com/vercel-labs/web-interface-guidelines | MIT | Web accessibility, focus, forms, motion, navigation, layout, and copy |

The Impeccable and UI/UX Pro Max directories are focused reference bundles, not complete copies of upstream CLI tools or searchable datasets. Their local SKILL.md files document the missing runtime/catalog boundaries.

The previous public prompt at `public/assets/aistudio/ha_74c228cd.md` is preserved at `.gemini/prompts/exportflow-ui-ux-master.md`. Generated Studio assets are removed from the public asset tree; the Worker-generated SVG remains the canonical favicon.
