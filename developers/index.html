01 / API SURFACE

Small, useful endpoints.

POST

/api/track

Track one shipment and receive a normalized event timeline, source provenance, conservative confidence and evidence-based insights.

POST

/api/batch-track

Track up to five shipments in one request. Each result carries its own HTTP status so partial failures do not discard successful items.

GET

/api/carriers

Read the installed carrier ID catalog. Catalog presence is not a live-tracking guarantee.

GET

/api/coverage

Read catalog-derived country classifications: direct adapter, universal fallback, link-only or not listed.

02 / QUICK START

Use the JavaScript SDK.

No API key is required for the current public lookup surface. Install no package: the lightweight ES module can be imported from ExportFlow or copied into your own build.

Browser or modern Node.jsDownload SDK module
import { createExportFlowClient } from "/exportflow-sdk.mjs";

const exportflow = createExportFlowClient();

const shipment = await exportflow.track({
  number: "LX123456789CN",
  language: "en"
});

console.log(shipment.status);
console.log(shipment.truth.latestTrusted);
Batch trackingMaximum five per call
const batch = await exportflow.batchTrack([
  { id: "order-1001", number: "LX123456789CN" },
  { id: "order-1002", number: "RR123456789BD" }
]);

for (const item of batch.results) {
  if (item.status === 200) {
    console.log(item.id, item.data.status);
  } else {
    console.warn(item.id, item.data.error);
  }
}

03 / OPERATIONAL CONTRACT

Know the boundaries.

Single lookup bodyUp to 4 KiB
Batch request bodyUp to 12 KiB and five shipments
Per-runtime request limit12 single lookups per minute; each batch item uses the same limit
Concurrent lookupsSix per runtime instance
Lookup budget25 seconds per carrier lookup
Supported language codesen, ar, es, zh, hi, pt, fr, bn
AuthenticationNot required for the current public read/lookup API

Rate limits are isolate-local safeguards, not a contractual global quota. They may vary across Cloudflare runtime instances. Do not build a high-volume commercial workflow on the current public limits.

04 / PRIVACY & EVIDENCE

Do not confuse a catalog with a verified network.

ExportFlow does not provide account-backed server-side shipment history in this version. A lookup sends the tracking number to ExportFlow's server and, when the selected carrier adapter requires it, to that upstream carrier. API responses do not echo the submitted number. Do not submit someone else's tracking number without authorization.

Carrier catalog entries, country mappings and adapter metadata are discovery information—not proof of a successful live lookup, an official partnership, or delivery coverage. Shipment confidence remains conservative when source-quality evidence is unavailable. ETAs are shown only when reported by the carrier.
